# La Maison — App Web de Restaurante

Aplicación web de una sola página (SPA) para un restaurante: menú, carrito, pedidos a domicilio/recoger/comer en el local, reservas de mesa y un panel de administración. Construida con **HTML + CSS + JavaScript puro** (sin frameworks ni backend); los datos (usuarios, productos, pedidos) se guardan en `localStorage` del navegador.
